# Hinglish review sheet

`hinglish.csv` (226 lines). For each row fill `ok_fix_cut`: **ok** (sounds natural, fine), **fix** (put better wording in `suggested`), **cut** (remove). Use `notes` for anything else (too formal, too cringe, offensive in some region). Slots like {app} and {minutes} must stay as written.
Open it in Google Sheets/Excel on a phone. Send the filled file to the Owner. WRITER will apply it and only then mark lines `native_reviewed`; until a real reader finishes, nothing is marked reviewed.
