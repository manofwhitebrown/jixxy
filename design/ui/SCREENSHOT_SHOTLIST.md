# Screenshot shot-list (T-U3-8, UI)

**Decision:** no screenshot-test library for now. Nobody can run a device in the sandbox, and a JVM tool such as Paparazzi is a new test dependency that PLATFORM/DEVOPS must approve and that renders from code, not from the real app. DEVOPS's emulator job already installs the app and uploads screenshots (`ci-evidence` release); GROWTH can use those for the first marketing shots. For anything better, the Owner takes the real shots below.

**Owner, how (5 minutes):** install the `latest` APK, use dark mode, set the phone to English, take each shot with the phone's normal screenshot (power + volume down). Send them in one batch; name them as the numbers below.
